## 已完成的 UI 與重要決策

- 由原始 Excel 導入 **119 筆設備**，另有 **1 筆明確標示的假報廢例子**。來源疑點仍保留在「待確認清單」，不能把原始資料當成已核准／已校正。
- 類別 → 子類別 → 工具規格群組 → 個別設備。各層清單有代表照片、建立與編輯；設備的類別、子類別、群組依順序選擇。群組共用以規格能力核對，不能只看照片。
- 報廢類別／子類別／規格群組與示意印章；報廢項目排除可用設備；真正報廢移轉流程未完成。
- 數量統一為每個選項一件，畫面只顯示單位；同固定資產編號的分件號獨立顯示、按既有號碼延續自動編號，不能重用已保留號碼。
- 移除「替換設備」操作；只使用新增及報廢。FQC 選設備在本檢具頁已移除，將來另開發。
- 校正方式選項：內部、外部、內部＋外部、不校正；週期：每週、每月、每季、每半年、每年、自訂（可輸入）；不另外維護方式／週期清單。
- 設備 Excel 匯出／匯入，含本頁資料及照片的示意功能；後續導入正式系統前需驗證來源資料及權限。
- 編輯旁邊的小型刪除按鈕設雙重確認，已核准版本維持歷史。篩選和詳細資料可收合，避免手機資訊過密。
- V1 歷史唯讀；按「開始修改／刪除資料」才建立 V2 草稿；可儲存、送主管審核、撤回送審；主管核准與發回都要填意見；核准後才產生生效新版本。詳見 `equipment-review-workflow.md`。
- 本機 IndexedDB 會在**同一瀏覽器**儲存草稿；切換裝置、瀏覽器或清除網站資料不能保證恢復。品質系統版本確認平台畫面是**預覽**，並非正式後台的真實送審。
