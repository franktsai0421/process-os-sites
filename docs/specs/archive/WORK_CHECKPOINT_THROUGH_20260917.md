## 歷史接續紀錄（不代表目前 Local 或正式部署狀態）

更新：2026-09-08，版本標記 3700（公開至 2026-09-13 12:00，曼谷／越南時間）。

- 公開網站已重新開放給所有取得連結的人，公開期限延長至 2026-09-13 12:00（曼谷／越南時間）。
- ADMIN 的整站備份與回復已修正：API 會自動建立必要資料表，本機與新環境不再因缺少 D1 資料表而回傳空白錯誤。
- 相同資料的重複同步現在視為成功但不建立新備份、不增加版本號，避免多頁籤輪詢造成無效備份暴增。
- 暫時性同步失敗會自動重試；權限錯誤或版本衝突仍會保留未同步資料並停止覆蓋。
- 帳號、密碼、角色與權限由 ADMIN 在平台內管理；使用者介面不再要求 ChatGPT Email 綁定。
- 製程送審依核准後台產品路線逐項檢查：只有產品實際包含的工段需要流程；必要工段至少要有一個套用該產品且內容完整的流程。
- 後台核准資料同步產品、類別、線別、工段與路線；新增必要工段會自動出現在對應類別工作區，BOM 更新會在送審與發送時重新核對。
- 發送前會驗證目前核准製程是否仍符合最新後台路線與 BOM；缺少資料時阻擋發送並要求回製程編輯台更新及重新送審。
- 流程編號下拉最多顯示 4 個可用號碼，已使用號碼不重複顯示。
- 發送監控與產線播放台的工段選單完整同步後台線別工段；所有已發送產品會保留顯示，不屬於該產品路線時明確顯示「此產品沒有此工段」。
- 修正系統範例版本自動補出的流程沒有箭頭連線、卻在發送時被判定未完成的矛盾；既有範例資料載入後會自動補齊同工段內的順序連線。
- 多項產品若遇到相同的送審／發送問題，警告只顯示一次，不再重複列出相同工段錯誤。
- 發送介面三個產品欄位會自動排除同一條線其他欄位已選的產品，已選產品不再出現在可選清單中。
- 新增 Windows 主機端完整 ZIP 備份與還原：預設 `.local-backups`，每週六越南時間 12:00 自動備份，錯過後於網站服務下次啟動補做，同週不重複。
- ZIP 內容包含完整程式、D1／SQLite、網站資產、上傳內容及備份設定；敏感內容以 AES-256-GCM 加密，`manifest.json` 記錄檔案大小與 SHA-256。
- ADMIN 備份介面可設定路徑／保留天數／時間、重新掃描、立即備份、下載、檢查、還原及刪除；還原與刪除需再次輸入密碼及確認文字。
- 還原前自動建立安全備份，驗證失敗不套用；還原期間開啟維護模式，套用失敗會自動回滾並留下不可由介面刪除的操作紀錄。
- Windows 系統工作因目前帳號沒有提升權限而無法註冊，已自動改用使用者「啟動」資料夾捷徑，登入 Windows 後會在背景啟動網站與備份排程。
- 修正本機管理檢查版無法登出：按「登出／切換使用者」會回到平台角色選擇畫面，不會被伺服器 ADMIN 身分自動登入覆蓋。
- 選定 ADMIN、RD 主管或製程人員後，該平台角色在重新整理後仍會保留；伺服器管理授權與畫面角色切換彼此獨立。
- 修正 Copy link 開啟的本機管理檢查版：`manage=1` 只在 localhost／127.0.0.1 生效，外部瀏覽器也能取得完整 ADMIN 資料後台、使用者與權限及整站備份；公開網域即使加上此參數也不會取得管理權。
- 發送介面的 A／B／C 線改為每個產品欄位先選「產品類別」，再只顯示該線、該類別的產品；同線其他欄已選的產品仍會自動排除。
- 備份與回復介面明確區分「本機硬碟完整 ZIP」與「雲端全站資料快照」；雲端 ADMIN 可立即備份、調整週六排程、回復及雙重確認刪除。
- 資料後台新增目前身分說明：員工公開查看不顯示使用者與備份管理；ADMIN 會顯示完整管理入口，避免不同瀏覽器看起來像版本缺漏。
- D 槽備份測試資料夾已確認為 `.local-backups`。
- 發送介面的產品欄位已修正溢出：卡片內欄位可正常縮排，選取後完整顯示產品編號、名稱與規格，選單項目也包含規格。
- 公開網站改用平台 ADMIN 帳號密碼向後端驗證；切換 ADMIN 並登入後可正常開啟「使用者與權限」及「備份與回復」，重新整理仍保留授權。
- 「備份與回復」及發送產品欄位已補齊越南文翻譯，切換 Tiếng Việt 時同步更新。
- 線上查核修正 ADMIN 登入資料合併時遺失驗證密碼的問題；重新登入後備份 API 會維持授權，不再出現只有 ADMIN 才能查閱的矛盾訊息。
- 備份方式、資料範圍、排程與備份原因說明補齊完整越南文，不再出現中越混合的管理畫面。
