# IPQC-AB／C 送審政策

狀態：Current confirmed requirements。2026-10-06 最新使用者要求取代先前三項例外及標準必填阻擋；適用日常程式，非隔離環境特例。共同規則見 [共享草稿](SHARED_DRAFT.md)。

檢查標準、錯誤名稱、方式敘述、檢查頻率、必要檢具尚未選擇、適用產品未完整涵蓋皆列待補，不阻擋送審／核准。與正式版相同也可送審並提示無實質修改。提醒保留對象、原因及修正入口，不補造內容。

已填但格式不合法、引用不存在、身分錯配、角色權限、待審鎖定、revision／CAS／generation 及固定案件防護仍保留。以明確 `missing` 分類處理內容缺漏，不能讓所有 `error` 通過。V3 與 IPQC legacy API 同步採用此分類。

AB working／Save 允許保留原有失效產品關聯，以便修改其他欄位和明確修復；不得新增失效關聯，送審／核准仍驗證引用。彈窗列出舊失效關聯，使用者明確取消勾選才移除；失敗保留輸入並顯示錯誤。

C 版本確認平台提供撤回入口，只依既有查看／撤回權限，不要求核准或發回權限。撤回必填理由並鎖定案件 ID，成功後確認平台與 C 後台同步。

2026-10-06 補充：具送審及審核權限的人員可自送自審 AB／C，適用所有環境；自審須明確確認並留下紀錄。審核、發回及撤回使用頁面內視窗，不依賴瀏覽器 `prompt()`；取消保留案件與捲動位置，錯誤在操作頁顯示。版本確認案件內容預設收折，操作按鈕集中呈現。

製程項目仍只取同線別／群組、產品、工段的啟用核准來源；同工段同項目只能分配一次。占用者須顯示方塊編號及移轉步驟。未核准來源提供品質來源入口，未選產品提供基本資料入口。項目標準、產品、方式、照片與頻率預設收折，展開後完整可讀。

資料操作驗收可在明確隔離副本使用真實來源，經正常 Save／Submit／Approve 後驗證製程選取、套用保存、重開及反向引用。不得直接改 status 冒充核准；日常資料由使用者送審／核准。

IPQC 分配頁以綠色「本流程已選」、藍色「其他流程使用中」、琥珀色「尚未分配」搭配文字／圖示呈現。分組收折時顯示已分配數量，勾選即時更新；標準明細預設收折。UI 標籤跟隨所選語言，來源標準原文保留。
