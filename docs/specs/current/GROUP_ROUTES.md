# 群組預設路線與產品例外

狀態：2026-10-08 追加產品移轉／畫布保全，實作與驗證見[接續報告](../../ipqc-reference/20261008-group-route-canvas.md)，Astra複審因唯讀連線 -32603 暫阻。2026-10-07 使用者確認需求；最大路線追加需求已實作，3020定向驗收與Astra第11輪獨立複審完成，逐項結果見[最新驗收](../../ipqc-reference/20261007-group-routes-max.md)；[前輪驗收](../../ipqc-reference/20261007-group-routes.md)保留歷史。

## 操作與資料

- AB／C 產線與類別，在產品清單上方顯示每個線別／類別的預設工段順序，提供查看、修改及安全移除設定；產品清單依實際跟隨模式顯示「跟隨群組預設」或「獨立設定」；獨立設定列出路徑，獨立清單也直接列出路徑，不再提供產品／例外的「查看路線」按鈕。
- 群組最大路線為同線別／類別全部產品工段的去重聯集，不受搜尋或分頁限制，例如 ABCD＋ABCEDE → ABCDE。優先保留產品路線一致的先後關係；順序矛盾形成循環時，先將循環縮成群組，只在循環內按工段主檔順序排列，保留循環前後的工段先後關係；依原始相鄰約束提示衝突產品（含重複工段回圈）。這是本轮保全資料的排序實作選擇，不視為使用者另行確認的業務順序。
- 既有手動預設與最大路線分開顯示，讀取不自動覆蓋。明確「採用最大路線」同次原子 Apply 更新群組及 routeMode：完全相同者繼承，其餘例外，每個產品原 stages 保持不變。
- 新增／修改產品有「套用預設路線」預覽按鈕，先改表單，按套用至草稿才同步；取消不寫入。已設預設時只改該產品；未設／已移除時清楚提示將建立群組預設，並原子建立，其他產品路線保持不變。切換類別重新取預設來源，但保留產品當前路徑；只有明確套用預設才替換路徑。
- 路徑相同但已明確例外者顯示「獨立設定 · 目前路線與群組相同」，仍列入獨立設定清單；群組修改不自動改其路線。讀取不修改模式。
- 群組 `defaultStages` 保存有序工段，產品 `routeMode` 為 `group` 或 `exception`；相容欄位 `products[].stages` 保留每個產品的有效路線，供 IPQC、製程、發送與播放共同讀取。尚未採用新設定的舊資料維持原行為。
- 群組修改只更新繼承預設的產品，明列受影響產品及保留的例外。移除預設設定會保留所有產品當時路線為例外，不刪工段主檔、標準、流程、分配或歷史。
- 使用既有 AB／C 整份草稿、手動儲存、固定送審與核准流程；核准前不改生效資料。保留權限、CAS、欄位、完整產品集合與工段排序相依 guard、待審鎖定與穩定 ID。
- 2026-10-30 使用者確認：製程畫布優先使用已核准群組 defaultStages 的工段與順序，即使全部產品僅走 ABC，群組 ABCD 仍顯示 D。沒有產品經過的可見工段顯示中越文提醒，保留既有方塊和歷史，不把零產品當成可刪除。沒有設定 defaultStages（含 null）的舊資料才使用產品最大聯集，保留既有去重與循環排序算法；空陣列表示明確沒有可見工段。路線移除只隱藏工段，保留完整流程、媒體、座標、連線、BOM 與 IPQC；加回後恢復，空群組不刪舊 workspace。IPQC-AB 選項限定群組有效路線；舊標準不因篩選而刪除，路線外既有標準另有可查閱入口。IPQC-C 仍按產品有效路線選工段。

## 介面與效能

- 每次開啟流程設定預設基本資料。
- 查明主資料載入、輪詢及重繪造成的捲動問題；未變更不重繪，變更時保留捲動及未套用輸入，縮減重複路線 DOM。
- 中／越文、桌面與手機尺寸驗證；保留真機未測界線。
- 2026-10-30 追加：主操作區永久顯示整個 AB（A、B 線）或整個 C 的儲存／送審範圍，篩選僅改顯示。「已同步到共用草稿」與「尚未儲存，請儲存後送審」分開呈現。
- 歷史入口分為唯讀版本／儲存紀錄與送審案件／還原；還原預覽標示整份範圍、產品／類別／線別變更筆數及未儲存內容將被取代。取消後可先儲存保留目前內容；確認套用仍須儲存、送審及核准，保留原權限與 revision 重確認。

## 驗收與邊界

先備份本輪開始時 3020 最新狀態。僅在既有 3020 隔離環境操作測試；不新增埠、不操作 3030、不覆蓋日常資料、不自動核准日常路線。檢查 AB／C 群組、產品例外、重排／移除、取消、Apply／Save／重整／正常核准、CAS 衝突、IPQC 選項與既有分配、製程畫布和下游路線一致。程式在共用 checkout 提供日常使用，資料變更由正常工作流生效。保留既有及並行未提交內容。
