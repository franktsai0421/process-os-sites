## 資料與識別

只保留 ERP 十欄：Mã NVL chính、Cấp、Số thứ tự、Mã NVL、Tên VP、Quy cách、ĐV、Lượng dùng tổ hợp、Mẫu số、Tỷ lệ khấu hao %。保留原文、項次前導零、L0 空料號、空白與 0；數值取原儲存精度，不改用累計欄或除以分母。原始 L2 以上的三個數值欄在匯入、編輯、比較、樹圖與匯出皆不使用。

按原始 preorder 層級建立 parent stack，深度不限於樣本 L4。同料號不同使用位置分開；識別為根主件加上每層項次／料號路徑。缺父層、重複且不可區分的位置、缺必要欄位在套用前拒絕，不靠品名、列索引或料號猜測。

首批以附件原 ERP 的 11 主件建立新 BOM 的規則僅適用當時明確授權的初始化，不能用來覆蓋較新的日常資料。2026-10-12 更新需求：一般匯入按穩定 occurrence ID 新增／更新，未出現的主件、子件及其後代均保留；較小報表不代表刪除或移動。真正刪除／移動須另列差異並取得明確授權。同報表重匯不得再產生差異。所有舊製程選取及歷史資料保留，不能確定的引用列提示，不自動清空或改接。

## 畫面與操作

搜尋編碼、品名、規格，大小寫、越文聲調與 đ/d 不影響比對，原文不改寫。上階列全部路徑；下階以目前選取項為查閱根，依完整後代組成分組並顯示相對層級，不重複列祖先路徑。相對層級只用於顯示；原始 ERP 層級、數值規則、編輯及匯出不變。森林包含全部關聯根與旁支，查詢節點藍底及勾記，選取位置加框。保留正常切換的視角，提供定位、平移、缩放；密集完整樹以可讀性優先。

預設唯讀，只有文字與允許的數值欄可改，結構欄鎖定。完成修改只修改本機編輯內容；放棄只回復本輪；上方儲存接收最後一個正在輸入的欄位，按整個 BOM 草稿保存。失敗保留內容與固定操作識別；未知結果只查原收據，不盲目重送。切換位置前須完成或放棄。

「匯入Digiwin報表」與目前主件／全部匯出同在比對區，收折後仍可用。先與包含未儲存修改的編輯內容比對，再逐欄採用、保留或修改。結構差異按主件依賴組處理，避免孤兒；套用時檢查基礎是否已變更。未套用比對不混入 Save。2026-11-04／05 草稿統一要求取代舊離頁提示：離開主頁或原生頁面可無提醒放棄未送本機修改／比對；搜尋與篩選保留內容。已送及未知操作保留原身分、世代、持久標記與收據查詢；不將舊無識別碼紀錄冒充 clean。匯出十欄與完整範圍不受收折影響，不要求它是 ERP 再匯入格式。

完成的有序手動／匯入操作，按一次「儲存草稿」以一次原子業務提交保存 working 與 saved；任一檢查失敗不得留下部分 Apply。修改權可存取，送審／核准／匯入各自授權。不同欄位按原 guards 合併；同欄、結構引用、匯入基準或世代衝突拒絕，不自行重算匯入選擇。實作與隔離驗證界線見[原子保存候選](../../acceptance/bom-atomic-save-20261105/README.md)。

## 既有工作流與消費端

沿用 V3 共享草稿核心、版本列、Save／Submit／撤回／核准／歷史、角色權限、CAS、待審鎖定及內容問題提示；不靜默自審，不新增因舊引用缺失而禁止送審的規則。舊 BOM 沒有該 scope，本次建立 `bom` adapter 接入同一核心，其他 scope 的草稿不變。

匯入請求維持 2,000,000 bytes 上限。新請求以 SHA-256 語意基底摘要替代完整基底，伺服器重新核對後才原子套用；不同基底拒絕 409。已開舊頁的過大請求仍拒絕 413，不提高上限或自動重送。已知拒絕不能顯示為結果未知／已儲存；輸入與操作識別保留，先保全再安排載入新版。

A/B 使用原始 L1 的料號、名稱、規格、單位、用量、分母、損耗；C 不顯示三個數值欄。引用保存 occurrence ID，保留既有互鎖；同码位置不合併，子件查詢不會讓原始 L2 變成可計量 L1。舊引用待確認，不能靠料號直接映射。
