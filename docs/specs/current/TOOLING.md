## 入口與共用流程

- 資料後台 → 品質系統 → 模具設備；越文主資料、中文輔助，名稱分欄保存。
- 直接使用當前 `VersionDraftUI`、品質色系、共用傳輸與 V3 kernel，草稿／操作紀錄／報錯／待補及按鈕與其他品質模組一致。整個模具庫一份 working、一份 saved、固定送審 case、正式 active；搜尋／篩選不縮小 Save／Submit 範圍。開始修改後不再顯示重複的開始按鈕；套用至共用草稿的器具、目錄與移轉可由頁首一起儲存。依 [2026-10-07 整份文稿政策](WHOLE_MODULE_DRAFT.md)，送審使用最後成功手動儲存的整份固定快照，不在送審時自動重存；未套用的彈窗輸入不包含在快照。
- 報錯、工作與快照待補、操作紀錄分區；手動儲存者／時間與同步狀態由真實事件取得。
- 保留身分權限、CAS、generation、operation receipt、待審鎖定與最後成功手動儲存快照。本輪明確要求模具「無實質修改不可送審」，在模具 adapter 阻擋，不改其他模組政策。模組存取者可編輯／儲存／送審／依既有授權撤回；核准與發回需既有權限，不為普通帳號新增核准權。ADMIN 可以明確確認自送自審並留下紀錄；匯入仍限 ADMIN。
- 本模組業務缺漏僅提醒，不擋儲存、送審、核准、撤回。解析、非法型別、非法引用新增、照片未上傳、日期互斥、並行衝突仍阻擋。此政策不得外溢至其他模組。
- 版本確認平台品質頁有独立模具案件區，整份送審及前後差異、修改者、理由、固定歷史；兩個撤回入口使用相同權限與 API。

## 器具與目錄

清單含縮圖、代碼、名稱、資產編號、数量／單位、正式位置／保管單位、狀態、操作。標題與控制文字按介面語言顯示，名稱分欄保留；查看、修改、刪除分開並保留間距，查看模式唯讀。允許缺資產碼、重複資產碼與同名；新增位於清單標題旁；只在可編輯草稿修改／刪除。照片支援多張及原圖。

編輯分為基本、IQC、移轉與歷史、檢查頻率四頁。照片及位置併入基本資料，位置在入庫日期附近，照片可直接預覽；基本資料保留類別、規格、生產商、入庫日期／日期遺失、啟用及停用原因、封存及原因、備註。檢查頻率採週、月、季、半年、每年下拉選單，空白只提醒；舊月份值可讀且未修改時不重寫。日期與遺失互斥；空日期且已遺失不警告；未填且未註記才提醒。停用與報廢／封存分開，封存核准後在一般正式清單隱藏，歷史保留，恢復須新草稿。

Danh mục 位於篩選下方、清單上方，同頁展開四區新增／查閱／修改；不另建導航、不做目錄搜尋或 enabled 欄位。器具類別自動 DC 編碼；內部保管單位只有名稱；供應商 SUP 與製造商 MFR 各有獨立 ERP、地址陣列、電話陣列、聯絡人陣列及各自新增控制。伺服器配置單調不重用的代碼；刪除須權限、兩次確認、無有效引用／歷史，否則改用封存。

## 位置、IQC 與移轉

位置分內部／外部，只選既有內部單位或供應商。數量大於一仍整組移轉，不拆件。正式器具的位置以新移轉紀錄變更，核准前不更新正式位置。新增前選擇新增移轉或更正，後者指定已核准歷史紀錄並新增獨立 `correctionOf` 紀錄。草稿可套用、儲存後再次修改，其他草稿移轉保留；待審鎖定、核准後唯讀，後續變動只能再新增或更正。已核准紀錄以日期、路徑及原因呈現，可收折歷史並開啟固定案件；不以「移轉 1／2」當標題。保留起訖、原因、系統時間、操作者及核准案件／版本關係，無模擬核准、無舊移轉核准事件。

IQC 新引用僅使用實際已核准、啟用且未刪除資料，唯一精確代碼映射 stable ID；多重、複合、未匹配保留原文待確認，不以名稱猜配。Picker 搜尋、類別複選、供應商複選；同維度聯集、不同維度交集；每頁八筆含原圖，選取跨頁／篩選保留，批次加入、去重、可移除。所選項目顯示小圖、原圖及正式來源詳情，返回保留彈窗输入與選取。Excel 映射原文仍保留於資料，不在編輯頁直接顯示。讀取失敗須重試，不能清空既有引用。

名稱／照片按原 stable ID 隨正式核准版本更新；草稿不可冒充生效內容。既有已停用引用保留、可查閱；新選取預設排除，可勾選包含停用但不得新增引用。移除來源保留原識別資訊與已核准歷史詳情，標示來源已移除／待重新對應；查看來源、重新選取及解除引用可用。恢复按原 ID；不得因相同編碼重新連到不同 ID。沿用 IQC 現有「既有編碼不可重編、編碼不可重用」規則，不另開重編通路。

新增移轉從目前已知位置（包含同草稿前序有效移轉）帶入唯讀來源，伺服器同樣核對，來源不符回報衝突。更正先讀選定已核准紀錄的來源、目的及原因，再新增獨立更正；不可覆寫原紀錄。更正早期事件不會倒轉其後已發生移轉。目的單位缺漏仍能送審、核准，但保留最後已知位置並列待補，不猜測或清空。每筆新移轉固定當時整組数量／單位及建立／修改人、時間；舊紀錄缺當時數量不以目前数量冒充。歷史摘要含操作者、時間、核准者、時間及版本，內文可查固定案件。

Local 銜接需正常 ADMIN、本機專用 API、正式整份核准且無開啟草稿／待審、來源摘要與目標 CAS、寫入前完整目標儲存備份、照片與 IQC stable ID 核對。只加入原本不存在的模具 control，保留全部版本、儲存快照、案件及歷史；目標已有不同模具資料時列具體衝突，禁止覆蓋。其他模組資料與 Git 分支不合併。實際結果見 [完整流程驗收](../../tooling/20261007-flow-acceptance.md)。

品質版本確認頁提供六個模組的待確認總覽及跳轉，待審自動展開，已處理模組與歷史可收折；歷史可查看內容差異、送審者與確認者／時間。載入失敗不顯示為零待審，復用各模組既有權限與確認入口，不更改其他模組的資料政策。
