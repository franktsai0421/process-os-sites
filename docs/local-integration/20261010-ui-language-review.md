## 改動

- 中越文各自顯示：回報入口、登入切換、載入／失敗／重試、版本通知、IPQC-C 頻率、FQC 與 IQC 標籤。切換語言不改寫使用者輸入、ERP 品名、既有紀錄與引用名稱；語言切換按鈕保留目的語言名稱。
- 共用 `interface-layout.css`：側欄名稱單行、越文按鈕不拆字；工具列可換列，小螢幕資料分頁可橫捲；流程名稱輸入框改為完整欄寬。收起裝飾英文與冗長範圍說明，完整範圍保留提示。
- BOM 樹枝垂直間距 104→78 px、欄距 258→244 px；移除上階位置卡的無用「查看此位置」。保留樹節點定位。原生捲軸區域不啟動拖曳，觸控使用原生捲動。
- BOM 使用共用版本草稿操作；待審入口轉往「主資料送審」。有未儲存修改、匯入比對或衝突時不送出舊快照；待審撤回標籤統一為「撤回送審」。
- 製程版本確認改為固定案件審核頁，保留既有權限、自審確認、內容待補確認與取消；不放置製程編輯／儲存／送審控制。
- 資料後台的例行報告分頁改為建置中；實際例行檢查入口與資料保留。
- 回報管理先显示載入狀態；避免舊帳號／舊路由回應覆蓋目前頁面，失敗可重試，資源載入失敗可恢復。
- 版本平台延後取得關閉的歷史內容及大型差異表；已採用 V3 時不先生成舊審核頁。品質審核不因非同步回應自動展開而推移畫面。語言翻譯觀察器去除重複子樹掃描。
- BOM 活動頁每 4 秒條件讀取；不打斷本機未儲存修改、輸入、對話框或匯入。帳號／請求序號隔離舊回應；BOM／模具正式版本 ID 納入更新通知。
