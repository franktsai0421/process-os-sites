# 製程平台 ChatGPT 討論包

狀態：2026-10-13 保存版，供設計討論；尚未改版或完成功能驗收。

本包以日常 port 3000 原本使用的目前工作區、目前分支及未提交內容為基準；不是 remote main、舊網站、3020、3035 或 3040 的合成資料。建立時 3000 已停止。最新版本資訊與檔案雜湊見包內 BASELINE.json 及 SOURCE_MANIFEST.json。

這次想討論的四個入口：產品製程狀態、發送介面、產線播放台、登入入口的「進入工段播放」。它們共同依賴製程編輯台、資料後台、版本確認平台及品質標準。先理解既有資料流與已確認條件，再提出改版選項。

## 建議閱讀順序

1. 本文件。
2. 01_現況與連動.md：七個頁面、資料後台與入口播放。
3. 02_資料版本與設計條件.md：草稿、生效、BOM/IPQC、權限與資料保護。

5. 04_討論問題與驗收範圍.md：未決設計與後續驗收。
6. 05_貼給ChatGPT的提示.txt：直接貼入新對話。

## 包含與範圍

包含目前 SPA、API、共用庫、schema/migration 定義、已審閱的程式內建資料與必要靜態資源、相關測試程式、现行規格與引用的文字證據。SOURCE_MANIFEST.json 列出實際範圍；來源副檔名為 markdown 的相對連結另有 LINK_AUDIT.json。

不包含本機 D1/R2 原始資料庫、實際帳號密碼／雜湊、有效登入、session secret、金鑰、.env、.dev.vars、私有備份、依賴目錄、Git歷史或部署設定。3050 的完整本機資料副本另留同機私有隔離目錄，不加入討論 ZIP。這份 ZIP 是閱讀包；不是可直接部署或復原日常資料的安裝包。

規格的 Current confirmed requirements、實作現況與日期固定的歷史證據必須分開。源文件中舊驗收的 PASS 不表示本次四頁改版、日常資料、正式發送或實體手機已通過。

## 3050 工作環境

新環境程式與 D1/R2 各自複製，僅重用已安裝 node_modules；不自動與3000雙向同步。3050 私有副本只將登入cookie改為 process_demo_3050，簽章secret重新產生；其餘程式與基準逐檔比對。後續修改應先指向3050 runtime，不直接改3000共享來源；正式整合、資料銜接與發布另依既有工作流程。隔離收據和重新啟動方式見同目录 06_3050使用與核對.md。
