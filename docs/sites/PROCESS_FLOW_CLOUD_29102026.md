## 既有語意
- `master:PROCESS` 為單一共享草稿，包含全部工段流程及其設備。
- 欄位同步／設備套用只改 working；儲存草稿固定 saved；送審只取最後成功 saved。
- 主資料版本確認處理 PROCESS；製程畫布另屬 process:platform。
- 撤回屬送審動作，退回屬審核動作。退回／撤回可重送原 saved；核准後無實質變更不得再送。
- 自審按既有明確確認及紀錄規則，不新增禁止或放寬。
