## 離開提醒：發現並修復缺口

原整合版本 `642d4de` 的十項補驗中，五項失敗：設備未套用時關分頁、重新整理（取消／確認），以及 working 已同步但未手動 Save 時關分頁／重新整理，均沒有瀏覽器提醒。五項原有保護通過：乾淨關閉、保存後離開、排隊命令、失敗命令、背景暫停／恢復。

局部修正 `app.js` 與 `process-equipment.js`，更新 `index.html` 資產版本：只在流程資料頁判斷未套用設備欄位／照片、名稱組字或尚未確認輸入、照片處理，以及 working 與 saved（尚未 Save 時與 active）差異。於 beforeunload 啟用瀏覽器原生確認。未編輯、改回原值、保存完成、待審鎖定及其他模組不新增提示。沿用傳輸層排隊／unknown／failed 保護，不重寫共享機制。

提醒處理不 POST、不自動套用／Save、不改權限或歷史。選擇留下時保留表單；明確離開時未套用表單會放棄，已 ACK 的 working 與已保存 snapshot 仍在伺服器，兩者不混稱。所有資料均為獨立 D1/R2 合成資料，操作者 Synthetic Frank。
