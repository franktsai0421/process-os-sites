## 最小修改與共用影響

產品僅修改 `public/process/index.html`：增加七行，在 URL 顯示意圖為 `view=data&dataTab=process-master` 且仍有 `data-process-boot` 時，使 `.app-shell` 暫時 `display:none`。原來的 `visibility:hidden` 仍會讓遮罩後方、不可見的初始頁面參與排版。沿原 bootstrap 移除遮罩旗標的時點顯示，不提前啟用操作。

顯示意圖不是授權；所有登入、目的頁授權、資料請求、讀取完成及錯誤處理沿原機制。離開提醒、草稿／審核、媒體與持久資料均未修改。選擇這個局部方案以避免重構共用載入器或改變 Excel 跨模組依賴。其他頁面及離開本頁後不套用此選擇器。

`index.html` 是與照片、權限、小幫手任務重疊的入口，dot 整合需保留這段條件及三個既有任務的資產版本，不整份覆蓋。固定分支的 merge-tree 結果與入口提案再次核對，見 [整合紀錄](integration-cloud-29102026/README.md)。沒有合併其他任務。

## 測量條件與重現

[完整原始資料、分段樣本與回歸結果](PROCESS_ENTRY_PROFILE_29102026_RESULTS.json)。同一機器、Chromium、1365×900、隔離 D1/R2、合成 Frank、2 工段／30 流程／40 設備；loopback 無節流、HTTP cache 關閉、OS cache 未清。五組交替測量，每次重建 fixture、Node 程序、瀏覽器及 context，測量期間沒有同時建置、lint 或其他瀏覽器測試。

為隔離變因，A/B 使用同一份 `cfc2c6a` 編譯伺服器與相同 JS/CSS；每次 fixture 啟動前只切換編譯輸出的 index：前版取自 `b307b8d`，後版取自 `cfc2c6a`。除了七行條件外，預覽橫幅的流程 SHA 也更新。每份結果記錄實際 index、bootstrap.js、app.js SHA-256；結束後恢復後版 index。這是受控入口比較，不是假稱兩套完整伺服器二進位比較。

量測程式：`PROCESS_PROGRAM_COMMIT=<實際編譯SHA> PROFILE_ROUNDS=1 PROFILE_VARIANT=<前或後> PROFILE_OUTPUT=<輸出JSON> node tests/process-entry-profile-browser.test.mjs`。預設五輪；本批以獨立程序交替各執行一次。`PROFILE_TRACE=<路徑>` 僅用於診斷，正式比較關閉。準備登入頁與輸入帳密不計時；從 click 呼叫到 15 個正確流程名稱、40 設備列、開始修改可用、shell 可見、ready 成立及兩個 frame，包含登入與自動化點擊等待。
