# 超過 500ms 項目：入口優化與重測 — 2026-10-30

## 結果與邊界

51 項入口操作（25 頁的開頁／重新整理，加登入）各版五次，共 510 筆，全部通過載入檢查、零 pageerror。各項中位數均下降，改善 4.2%～51.0%。6／51 項的中位數不超過 500ms；只有品質報告直接開頁的五次全都不超過 500ms，不能宣稱全站已達 500ms。最慢值並非全部改善。

本輪只修改共用入口與建置載入方式。沒有修改後端寫入、業務規則、權限、自審、版本衝突、照片格式或歷史；沒有 push、PR、merge 或發布。三選項離頁仍未接入 UI，整個原始任務仍未完成。

## 根因與修改

1. 前置樣式請求與 parser 等待：診斷樣本主頁 reload 833ms，其中 bootstrap API 37ms；API 約在 261ms 才開始。不是把全部載入時間算成 SQL。
2. 共用腳本請求／執行：同一診斷樣本 shared-ready 346ms、assets-ready 722ms，約 376ms 在共用腳本階段。
3. `index.html` 將既有 shared-state gate 移到樣式之前開始；仍由相同 fresh bootstrap 驗證身分／授權與資料目的地。
4. `lib/process-styles-build.mjs`、`vite.config.ts`：31 個固定 stylesheet 依原順序、保留原文合成 1 個。保留 /process/ 相對 URL 基底；遇到 import／charset／namespace、額外樣式屬性或破壞 cascade 的插入項目時拒絕不安全合併。
5. `lib/process-scripts-build.mjs`：48 個門後腳本變成 5 個請求。45 個通過檢查的 expression scripts（目前為既有 IIFE）合成兩組；vendor、editor-line-selection、app 的全域宣告保持獨立。原程式碼及先後順序不改、不 eval；private seed 不讀入合併檔。
6. `bootstrap.js`：合併檔執行到尾端才有完成記號，缺少記號即顯示載入失敗、停止後續腳本，不以缺少模組當 ready。資產檔名由內容雜湊產生；bootstrap cache token 更新。沒有跨使用者資料快取。
7. 原始腳本與 CSS 仍逐檔保存；只在建置輸出合併，最後仍經既有 public authentication boundary audit。開發原始 HTML 不依賴生成檔。

新增相依套件：無（建置分析使用既有 TypeScript）。設定／資料遷移：無。須重新 `npm run build` 才會產生合併輸出，不應手動提交 dist 或把舊 dist 與新 HTML 混用。

## 照片寫入拆量（單次案例，不當成五次改善率）

15 個照片入口功能案例均通過，包含照片保存、重新讀取、方向／尺寸與像素或原檔核對。18 次 Save HTTP 往返為 66～332ms。這不是「點按鈕到畫面可再次操作」的全程數字，也不是 SQL 純執行時間。

先前表的 Save→完整 fixture 讀回包含整份共享紀錄／照片快照解碼與輪詢；本輪記錄的讀回區間還可能與在途 POST 重疊，不能用相減宣稱精確 CPU／SQL 成本。該測試端成本不應被當作網站每次 Save 的寫入耗時。本輪未更改 Save 後端，不能把拆量說成保存加速。

## 未達標、未測及後續優先項目

- 45／51 項中位數仍超過 500ms，且多數最慢值未達標。登入與主頁等個別最慢值可能增加；不刪掉離群值、不以平均改善取代尾端延遲。
- 仍要載入／執行所有既有模組程式，合併請求沒有完成逐模組 lazy registration。下一步可按頁拆初始化依賴與 Excel 匯入匯出資源；預期降低首載傳輸／解析，影響共用啟動與跨模組 handler，需逐模組驗收，不能直接刪除載入。
- 製程設備照片 Apply 的 909ms：先用相同累積資料量重複五次，追蹤 handler／R2／snapshot 處理，再決定局部修正；不得省略引用、權限或 CAS。
- 密碼重設／改密碼含 KDF 及驗證登入，不適合以降低雜湊強度達成 500ms。可另外量 UI 保存與測試用新舊密碼登入，保持相同安全規則。
- 左側導航原本大多中位數低於 500ms；本輪跑功能回歸，沒有把不同時間的單次導航結果拿來算前後改善。
- 正式／既有站台、正式資料量、慢網路、斷線、長時間壓力、所有按鈕逐項瀏覽器時序仍未完整驗收。
- 三選項離頁、各草稿模組逐項完整送審／撤回／退回／核准瀏覽器驗收仍沿原交接列待完成。無業務規則變更；新建置合併可能改變初始化的微任務／事件排程，已跑上述回歸，但未宣稱所有整合路徑均驗完。
