# 製程平台 Round 5 前後實測速度

所有數字為雲端工作機內的隔離合成資料，非既有 process-os-test 站或正式資料。單位 ms。每版本每項5次，列中位數／最慢一次；正改善幅度表示變快，負值表示回退。

同一 Chromium、無節流、HTTP快取停用、每輪新登入context與相同資料reset；每版本各一個持續暖Worker，一次排除計時的smoke warmup，5組交替順序。OS快取未清，非冷機／冷Worker測試。量測期間無同任務並行build或其他測試；共享主機背景負載不受本任務控制。

主操作必須有必要ACK、正確狀態/DOM、寫入隊列空及兩個animation frames；理由填寫不計入確認操作，開窗另列。主操作不等待全部圖片。獨立持久化讀回列在原始checks.verificationMs，不冒充SQL時間。C只查詢，無C分配/套用新增功能。
