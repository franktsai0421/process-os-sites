## 重現、根因與修正

- 修改前 AB、C 產品 Apply 各 5 次皆出現 `Cannot read properties of undefined (reading 'products')`。目的頁 scoped projection 不載入另一個 catalog，表單卻無條件讀取它。修復本地提示的空值處理，後端跨範圍唯一性／CAS 保持；線別／工段表單同類問題一起修正。
- baseline 未修改 Begin 後可以切頁；未重現使用者既有站台「單純停留就 UNKNOWN」的全部條件，不能把此候選說成現場根因已完整確認。
- 共用切頁原本只有拒絕路徑，缺少「確認 Save → 成功 → 原目標」續行；master 原 canLeave 僅看 busy。新增有明確 requiresSave／saveForDeparture 的 adapter，Save 後再次檢查 owner、dirty、最新目標，不清旗標。
- 新草稿沒有 saved 時，與 active 相同應是「尚無變更」，不要求手動 Save。
- 注入真實 Save 成功、回應遺失及收據 GET 失敗：UNKNOWN 必須保留，不能重送或切頁。查詢收據後到重新讀回 saved 的空檔曾可觸發第二次 Save；現於整段 recovery 保持 busy，確保只發出一次原 Save。
- 保留 cancelled／rejected／unknown 表單及寫入狀態。過期帳號物件、auth epoch 或 delivery ACK 不安裝回目前資料。IME 組字結束才重算搜尋，不重建輸入框。
