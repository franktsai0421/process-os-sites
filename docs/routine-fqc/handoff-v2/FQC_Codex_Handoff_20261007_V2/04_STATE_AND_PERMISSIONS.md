# 狀態與權限落地表
本表是02規格的工程整理，不建立新權限角色。伺服器必須逐動作核對現有帳號權限；建立人是負責人，不代表獨占草稿。

|對象/狀態|動作/條件|下一狀態/保留|
|---|---|---|
|未啟用排程|設定權限選日期、預覽、確認|已設定；到起始日依期別產生，防重複|
|計畫草稿|編輯/Save/Submit，固定成功Save快照|待審，該份鎖定|
|計畫待審|有權限者核准/發回；可依權限撤回|已核准或回可編輯，保留案號歷史|
|已核准計畫，無報告|有權限者填理由反確認|回可編輯，保留核准與反確認|
|已核准計畫，有報告|修訂，更正不能覆寫舊版|新舊版本連結與影響待辦|
|報告草稿|樣品與逐項結果、照片；Save可不完整|已存草稿|
|報告草稿|Submit驗證最後Save快照，不合格說明＋照片必備|待審或指向缺漏項目，保留輸入|
|報告待審|核准/發回/撤回需權限與CAS|正式報告或回可編輯|
|核准合格|完成該項本期安排|不是所有涵蓋產品都已實測|
|核准不合格|建立或連接對應異常，重試防重複|待改善；該次報告正式保留|
|無法測試|審核留存後，核准補測安排或本期免做|補測待辦或免做完成|
|無法判定|補充判定/複測及核准|依結果完成/轉異常|
|異常改善中|紀錄改善、建立獨立複測報告|待複測/待複測審核|
|複測仍不合格|可正常送審核准，每次都有說明照片|回待改善，保留每份歷史|
|複測合格且核准|有權限者確認結案|改善合格結案|
|不再複測|原因＋處置＋證據申請，主管/Admin核准|不合格・處置結案|
|計畫部分完成|還有未做、待補測、無法判定|不可整份完成|
|計畫各項完成/免做|更新完成統計|計畫完成；異常可仍未結|
|正式報告需改|修訂/更正，查影響|原版不可覆寫|

Admin自審需確認與紀錄；普通編輯者不獲額外approve權。停用帳號、非法引用、CAS、待審鎖仍保護。BOM例外僅限本例行執行流程。
關鍵資料關係（建議）：應檢工作→計畫明細→報告明細→樣品結果列；異常案件→改善紀錄/複測報告；免做與處置結案各有核准紀錄。ID穩定、版本不可變、每次寫入可識別重試；具體儲存沿用現有安全架構，不因本建議重灌資料。
